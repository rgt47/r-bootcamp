# R for Biostatistics: A One-Week Boot Camp
*2026-04-27 11:00 PDT*

A short preparatory course for incoming graduate students in
biostatistics and adjacent programmes who arrive with no or
minimal R experience. Five days, one chapter each.

## Structure

- **Day 1** Setup and First Steps
- **Day 2** Data Import and Manipulation
- **Day 3** Visualisation with ggplot2
- **Day 4** Functions, Control Flow, Applied Statistics
- **Day 5** Reproducibility and AI Assistance

Each day is approximately 1 hour of lecture content + 2
hours of homework with worked solutions. No examinations.

## Build

```bash
quarto render
```

## Position in the series

The boot camp is the entry point to a five-volume graduate
biostatistics sequence. After Day 5, the four companion
volumes pick up where the boot camp leaves off:

- *Biostatistics Practicum* — workflow infrastructure
- *Statistical Computing in the Age of AI* — methods and
  computing
- *Advanced Statistical Computing in the Age of AI* —
  advanced computing
- *Applied Generative AI for Public Health and
  Biostatistics* — generative AI

A sixth volume, *Applied Statistical Methods for Public
Health*, covers the applied methodological core (causal
inference, longitudinal, survival applied, clinical
trials, missing data, meta-analysis).
